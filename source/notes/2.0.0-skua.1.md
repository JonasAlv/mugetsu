**The game player bundled with [Skua](https://github.com/brenohenrike/Skua) / [Bonxie](https://github.com/retr0gr4d3/Bonxie).** The client downloads this release automatically; you don't need to install it separately.

## Skua build 2.0.0-skua.1
- Updated base player to **Mugetsu 2.0.0** (frame interpolation, uncapped/FPS-limit pacing, memory limit & trimming, colour-custom fix, and right-click menu).
- Added `SkuaInput::MugetsuSetting` over `--skua-bridge` for live Mugetsu 2.0.0 settings (`performance`, `interpolation`, `uncapped`, `fps_limit`, `memory_limit`, `free_memory`, `show_fps`), alongside forwarded `Resize`, `MouseMove`, `MouseButton`, `MouseWheel`, `Key`, `Text`, `Focus`, `Visible`, and `ClearKeys`.
- Preserved Windows `--skua-parent` / `--skua-bridge` embedding and Linux `SKUA_EMBEDDED=1` support.
- x86-64-v2 build included for processors without AVX2.

Mugetsu 2.0.0 plus `source/patches/skua.patch`:
- `--skua-bridge host:port`: connects to Skua/Bonxie to bridge `ExternalInterface` calls/events and forwarded `SkuaInput` events. The player exits when the host closes the connection.
- `SKUA_EMBEDDED=1` (or `--skua-bridge`): disables update checks and resize-on-metadata.
- AVM2 `JSON.stringify` omits built-in `Event` properties (`type`, `target`, etc.) and `.0` on whole numbers `< 9e15` for AQW compatibility.
