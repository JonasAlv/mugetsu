## Skua build 2.0.3-skua.1

Mugetsu 2.0.3 (upgraded from 1.6.0, including Performance mode, DirectX 12 default on Windows, memory limit and unused gear cleanup with Free memory now, frame pacing and FPS limit, frame interpolation fixes, colour-custom, `/spellcraft` ink and rune glow fixes, 1440p/4K room tint fixes, broader 64-bit processor support, and Ruffle 2026-11-10) plus `source/patches/skua.patch`:

- `--skua-bridge 127.0.0.1:port` — loopback-only TCP bridge for `ExternalInterface` calls, game events, and live `mugetsu_setting` updates from Bonxie's Options → Applications
- `--skua-parent <window handle>` — embeds as a borderless child window on Windows with `SetFocus` on click (`SKUA_EMBEDDED=1` on Linux, where Bonxie handles embedding)
- Runtime `VERSION` and Windows `ProductVersion` / `FileVersion` set to `2.0.3-skua.1`, with the standalone update check and resize-on-metadata disabled when started by Bonxie
- Exits cleanly when the bridge connection closes or the embedded surface is lost
- AVM2 `JSON.stringify` fixes for AQW (`Event` getters omitted, whole numbers `< 9e15` serialized without `.0`)

Without those options it behaves like Mugetsu 2.0.3.
