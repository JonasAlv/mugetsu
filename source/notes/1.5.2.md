## New in 1.5.2 (VibeSkua Linux Edition)
- **AVM2 JSON cyclic structure fix**: Strips event dispatcher getters (`type`, `bubbles`, `cancelable`, `eventPhase`, `target`, `currentTarget`) during JSON serialization in ActionScript, preventing recursion into SmartFoxClient / Error #1129.
- **Whole number formatting**: Serializes finite whole numbers without decimal fractions (`383618675`, not `383618675.0`), resolving ActionScript and bot packet/monster ID mismatch.
- **HTTP Navigator timeouts**: Configured 15s connection timeout and 30s read timeout on reqwest client to prevent freezing on *"Authenticating Account Info..."*.
- **VibeSkua Linux IPC**: Unix Domain Socket IPC bridge and XEmbed support for seamless embedding and automation in VibeSkua on Linux.
